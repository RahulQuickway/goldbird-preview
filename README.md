# Goldbird Security & Facility Services – static website

Plain HTML/CSS/vanilla JS. Pages are generated by `_build/build.py` (run with a Python that has Pillow):

    /workspace/.venv-img/bin/python _build/build.py

- Edit content in `_build/content.py` (service pages) and `_build/build.py` (home, about, gallery, careers, contact).
- Shared header/footer, contact details and the WhatsApp number live in `_build/common.py` (WA number also in `assets/js/main.js`).
- Forms have no backend: on submit they open WhatsApp (wa.me) with the form fields and show a mailto fallback.
- Search the HTML for `PLACEHOLDER` to find spots waiting on verified client facts (years, clients, PSARA/GST, testimonials, social links).
- Preview: `python3 /workspace/serve_goldbird.py` (port 8792; clean URLs + custom 404). A copy is in `_build/serve_goldbird.py`.
